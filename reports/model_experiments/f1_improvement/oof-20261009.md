# F1 Improvement — Train-only 5-fold OOF

Date: 2026-10-09  
Status: **TRAIN-ONLY OOF PASS; NESTED HYPERPARAMETER SEARCH NOT STARTED**

## Scope and integrity

One deterministic, stratified 5-fold OOF run evaluated the locked ML-LC-05 XGBoost configuration on the existing 807,210 Train rows. Each fold's preprocessing and model were fit on the other four Train folds; predictions were written only for that fold's held-out Train rows. No Validation or Frozen Test rows were read. No primary model, manifest, Dashboard, or Dash artifact was changed.

The OOF threshold was selected from pooled OOF predictions and labels. Consequently, the selected-threshold F1 below is selection-biased and is an exploratory threshold-selection result, **not** an independent performance estimate. This run did not tune model hyperparameters or refit a replacement model.

## Results

Five-fold OOF, seed 42; XGBoost parameters: `n_estimators=200`, `max_depth=4`, `learning_rate=0.05`, `subsample=0.8`, `colsample_bytree=0.8`, `random_state=42`, `objective=binary:logistic`, `eval_metric=logloss`, `tree_method=hist`, `n_jobs=4`.

| OOF threshold policy | Threshold | Precision | Recall | F1 | Accuracy |
|---|---:|---:|---:|---:|---:|
| Fixed 0.5 | 0.500000 | 0.604430 | 0.076372 | 0.135609 | 0.805619 |
| Prior locked Validation threshold, applied only to Train OOF | 0.220095 | 0.345977 | 0.602089 | 0.439440 | 0.693323 |
| Selected on pooled Train OOF | 0.210676 | 0.337641 | 0.631482 | 0.440015 | 0.679101 |

At the selected Train-OOF threshold, confusion matrix `[TN, FP, FN, TP]` is `[446408, 199643, 59390, 101769]`; predicted-positive rate is 37.34%. The F1 difference versus applying the locked threshold to the same OOF predictions is only **+0.000575** (about +0.058 percentage points), with lower precision and accuracy and higher recall. This is not evidence of a meaningful or independently validated F1 improvement.

Threshold-independent Train-OOF ranking/probability diagnostics: ROC-AUC **0.723362**, Average Precision **0.399711**, Log Loss **0.447826**, Brier **0.142646**. These are exploratory Train OOF metrics and must not be compared as if they were independent validation/test results.

Fold F1 at the selected pooled threshold: 0.440887, 0.440900, 0.437855, 0.440435, 0.440001. The pooled threshold was selected using these same OOF labels; fold metrics do not remove that threshold-selection optimism.

## Decision

The memory guardrails were not exceeded, and the OOF step completed. The threshold-only F1 gain is negligible. No model candidate is promoted. Nested hyperparameter search remains a separate, compute-heavy step (up to 58 sequential fits under the existing protocol) and is **not started in this run**. Any later claim of improved generalization requires an untouched/prospective evaluation; the Frozen Test remains sealed.
